# Бие даалт №1 — Code Quest

**Хичээл:** APL121 Алгоритм, программчлалын хэл
**Сэдэв:** Оюутны голч дундаж (GPA) ба шилдэг 3 оноо тооцох

## Асуудал

Оюутны хичээл бүрийн оноо, кредитийг оруулахад программ хичээл бүрийн голчийг тооцож, нийт GPA болон хамгийн өндөр 3 оноог хэвлэнэ.

## Ажиллуулах

~~~
cd bd1
gcc main.c -o main
./main
~~~

## Жишээ гаралт

Оролт: 5 хичээл; оноо 90, 98, 86, 76, 86 (кредит бүгд 3)

Хичээл 1: оноо = 90, голч = 3.7
